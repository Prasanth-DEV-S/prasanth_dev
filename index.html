About Me

Passionate about clean code, modern Android APIs, and seamless user experiences.

I specialize in native Android application development with a strong focus on modern architectural patterns such as MVVM and MVI. With Kotlin as my primary language, I build declarative interfaces using Jetpack Compose and manage asynchronous data streams using Kotlin Coroutines and StateFlow.

Whether building offline-first local databases with Room, connecting to RESTful microservices with Retrofit, or maintaining robust dependency injection with Hilt, I strive to write clean, maintainable, and well-tested code.
